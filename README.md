# Desafios Diários de Programação

Repositório dedicado à resolução de desafios diários de programação, propostos por uma comunidade de mulheres na tecnologia.

A proposta é praticar lógica de programação, desenvolver o raciocínio computacional e explorar diferentes formas de solucionar problemas, utilizando a linguagem de programação de minha escolha.

## Objetivos

- Praticar lógica de programação e algoritmos.
- Desenvolver habilidades de resolução de problemas.
- Aprimorar conhecimentos em linguagens de programação.
- Registrar minha evolução e manter a constância nos estudos.

## Linguagens e tecnologias

Os desafios podem ser resolvidos em diferentes linguagens de programação, conforme os conhecimentos adquiridos ao longo dos estudos.

**Linguagem inicial:** Python.

## Organização do repositório

Os desafios são organizados em pastas individuais, identificadas pelo nome do desafio e pela data de resolução no formato DDMMAAAA.

Exemplo: um desafio resolvido em 07/11/2026 será armazenado na pasta validador_de_senha_07112026/.

Exemplo de estrutura:

```
desafio_do_codigo/
|
├── validador_de_senha_07112026/
│   └── solucao.py
│
├── nome_do_desafio_08112026/
│   └── solucao.py
│
├── nome_do_desafio_09112026/
    └── solucao.py
```

## Como executar

Para executar uma solução desenvolvida em Python, utilize o terminal na pasta raiz do repositório:

```bash
python validador_de_senha_07112026/solucao.py
```


## Metodologia

Cada desafio representa uma oportunidade de aplicar conceitos estudados, testar abordagens e aprimorar a escrita do código.

As soluções são desenvolvidas como parte do meu processo de aprendizagem e podem ser revisadas ou refatoradas conforme minha evolução.

## Sobre a iniciativa

Os desafios são compartilhados por uma comunidade de mulheres na tecnologia, que incentiva a aprendizagem contínua, a troca de conhecimentos e a prática de programação.

Este repositório reúne minhas resoluções individuais e tem finalidade educacional.
